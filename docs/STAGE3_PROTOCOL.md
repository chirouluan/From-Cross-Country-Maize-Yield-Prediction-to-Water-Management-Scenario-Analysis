# Stage 3：基于现有数据的产量风险诊断与适应策略

## 1. 定位

参考论文贡献的是“实际基线—受约束情景—综合策略”的分析结构，而不是要求本项目复现其氮投入变量。CY-Bench 当前数据没有施氮量、氮吸收、灌溉处理、品种或耕作措施，因此 Stage 3 不估计这些处理的响应，也不输出施氮处方。

Stage 3 回答的问题是：在 Stage 2 判断某个行政单元某年存在产量风险后，哪些已经观测到的环境或作物状态偏离了当地高产历史参照；在保守、可行的数据边界内，水分环境恢复情景对应多大的模型产量差异；LLM 能否把这些证据转成有前提和边界的适应性建议。

## 2. 数据层

每个国家直接读取前两个阶段保存并通过 SHA-256 校验的产物：

- Stage 1 `dataset_hardcoded.csv`；
- Stage 2 `predictions_tabpfn_base.csv`；
- Stage 2 `predictions_tabpfn_cn_finetuned.csv`。

Stage 2 的预测文件包含 5 次重复。Stage 3 先按 `adm_id、year、model、split`
汇总：预测均值用于风险触发和决策上下文，样本方差与标准差作为预测不确定性
一并保存；不会任意抽取某一次预测。

两个 Stage 2 预测是必需输入，而且其 manifest 中记录的 Stage 1 SHA-256 必须与当前特征数据集一致。Stage 3 会保存完整的 `decision_input_snapshot.csv` 和 `model_training_data.csv`，后续检查不需要重新运行 Stage 1/2。

主键是 `adm_id, year`，目标是 `yield`。真实特征包括：

- 固定背景：`awc`、`bulk_density`；
- 水分代理：名称包含 `prec`、`cwb`、`ssm` 的特征；
- 温度风险：`tavg`、`tmin`、`tmax`、`gdd`；
- 辐射风险：`rad`；
- 作物状态指标：`ndvi`、`fpar`。

Stage 3 不做缺失值插补。关键数据存在缺失或非有限值时直接停止，并报告字段。

## 3. 防泄漏参照

目标年份可由 `--target-year` 指定；未指定时，对每个 `adm_id` 使用最新年份。每个目标记录的高产参照只使用比目标年份更早的数据：

1. 当地历史记录不少于 5 条时，使用同一 `adm_id`；
2. 当地历史过少时，退回同一国家的历史记录；
3. 取历史产量上四分位附近的记录作为高产参照池；
4. 每个特征以参照池中位数为目标，以 IQR/标准差衡量偏离程度。

产量响应代理采用 ExtraTrees，并用训练期内最新 30% 年份执行滚动前向验证。最终代理只使用严格早于所有决策记录最早年份的数据拟合，不允许目标年份真实产量进入模型。该代理用于解释情景，不替代 Stage 2 的 TabPFN 跨国泛化结论。

## 4. 分层情景

### S1：实际环境状态

保留目标记录的所有实际特征，报告响应代理预测区间，并在存在 Stage 2 输出时同时保存基础 TabPFN 和 CN 微调 TabPFN 的预测，作为风险上下文。

### S2：胁迫诊断与水分恢复情景

逐特征比较实际值与高产历史参照。诊断分数同时考虑：

- 标准化偏离程度；
- 模型特征重要性；
- 单独移向历史参照时的正向模型差异。

优化层只能改变水分代理。每次最多把代理值向历史参照移动默认 50%，并裁剪在目标年份之前观测分布的 10%–90% 分位范围内。候选变化只有在模型预测改善时才接受。

这个情景表达“如果水分状态部分接近历史高产条件，模型预测会怎样变化”，不表达需要灌溉多少，也不证明灌溉必然产生该效果。降水本身不可控制，但可作为缺水或过湿风险证据，辅助判断灌溉、保墒或排水的必要性。

温度、辐射、土壤、NDVI 和 FPAR 不参加数值修改：它们分别对应天气风险、固定背景或作物状态结果。对这些变量只能生成播期、品种和监测等适应性建议。

## 5. LLM 耦合

Qwen Base 和 Qwen RAG 使用同一个 `LLM/Qwen3.5-9B`。RAG 分支额外读取经过国家、作物和时间边界过滤的 `climate_rag_metrics.csv` 数值证据；不加载 adapter，也不进行向量搜索。两个分支分别承担两个受约束任务：

1. 提出高产参照分位数、胁迫阈值、水分代理最大移动比例和候选数量；程序把输出裁剪到硬边界。
2. 将 `adm_id/year/feature` 级证据映射为有限动作词表：灌溉可行性评估、保墒、排水评估、播期复核、耐逆品种复核和田间监测。

LLM 不预测产量、不创造项目中没有的管理变量，也不能引用不存在的证据。输出完成后自动检查行政单元、年份、特征名和动作词表；只有完全匹配的建议才记为 grounded。

## 6. 比较与报告

Base Qwen 与 RAG Qwen 的比较至少报告：

- 约束提案差异；
- 接受的水分代理变化数量；
- 情景模型差异；
- 建议证据落地率；
- 专家对可操作性、风险意识和越权程度的盲评。

任何结果都应称为“模型情景”或“条件式适应建议”，不能称为经过田间验证的管理处方或因果增产措施。
